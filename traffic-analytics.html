What connecting requires (v2)

  1. Verify site ownership in Google Search Console.
  2. OAuth consent: you'll sign in with Google and grant read-only Search Console access — handled by the v2 backend, never in frontend JavaScript.
  3. API keys stay secret: all credentials live on the backend. They are never placed in HTML or app.js.
  4. GitHub Pages hosts only static files, so v2 adds a small backend service for the OAuth flow and data storage.
Our promise: no bot traffic, no fake clicks, no traffic exchange. If a number appears here, it came from Google.
