❓ Help

How each tool works, in plain English.

🔍 Keyword Finder

Type your topic or product name and pick a keyword type. The tool generates structured keyword ideas — each with search intent (informational / commercial / navigational), a suggested page and a content angle for the USA market. Tick the ones you like and send them to the Content Planner. Note: v1 shows ideas, not real search-volume numbers — we never invent data.

📝 Content Planner

Choose a keyword from the Finder (or type your own) and generate a full plan: title options, meta description, H1, H2 sections, FAQ ideas and internal-link suggestions. Save plans and move each through Idea → Planned → Draft → Published. You can copy any plan with one click. Nothing is published automatically — you review everything first.

🩺 SEO Audit

Enter any page URL to check its title, meta description, H1, canonical tag, robots tag, mobile viewport, sitemap and load time. Results are marked ✅ pass, ⚠️ warning or ❌ fail with plain-English explanations. Because of browser security, pages on other websites may be blocked — pages on this site audit fully, and a server-side audit comes with v2.

📊 Traffic Analytics

Connects to Google Search Console in v2 to show real impressions, clicks, CTR, average position, USA traffic by page and top keywords. Until then it stays honestly empty — we never show fake traffic.

⚙️ Settings

Save your website URL (used by audits and link suggestions). Export your keywords and plans as JSON, import them on another device, or clear everything. All data lives in your browser only.

Frequently asked questions

Is Website SEO Pilot really free?

Yes. All v1 tools run entirely in your browser — no account, no payment, no API keys needed.

Where is my data stored?

In your browser's local storage. Nothing is uploaded to any server. Use Settings → Export to back it up.

Why doesn't the Keyword Finder show search volume?

Real volume data requires a paid keyword-data provider. Showing invented numbers would be dishonest, so v1 gives you structured research ideas instead. A real data provider is planned for v2.

Will the SEO Audit guarantee rankings?

No — and no honest tool can. The audit finds technical issues that block good rankings; fixing them is necessary but not sufficient. Rankings also need good content and real backlinks.

Why is Traffic Analytics empty?

It only displays real Google Search Console data via OAuth, which needs the v2 backend. We refuse to fake traffic numbers or count test visits as organic clicks.

Our SEO rules

  1. Only real SEO tools and genuinely useful content.
  2. No bot traffic, fake clicks, traffic exchange or auto visitors.
  3. No artificial manipulation of Google search results.
  4. API keys and passwords are never stored in public frontend code.
  5. Content is written in English for USA readers.
  6. Every public page has its own title, meta description and canonical URL.
  7. Sitemap and robots.txt are configured correctly.
  8. No SEO data is shown unless it is real — never guessed.
  9. Every content plan is reviewed by you before publishing.
  10. Real organic traffic is measured with Google Search Console.
